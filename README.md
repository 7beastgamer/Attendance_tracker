# Attendance Tracker

## Overview

**Attendance Tracker** is a modern web application designed to simplify the process of tracking student attendance. Built with **React**, **TypeScript**, **Vite**, and **Firebase**, the app provides real‑time attendance management, QR‑code check‑in, and an intuitive admin dashboard.

## Features
- **Realtime synchronization** using Cloud Firestore.
- **QR‑code scanning** for fast, contactless attendance marking.
- **Admin dashboard** to view class rosters, attendance history, and generate reports.
- **Firebase Authentication** (email/password) for secure access.
- **Responsive UI** powered by Tailwind CSS, ensuring a great experience on desktop and mobile devices.
- **Easy deployment** to Firebase Hosting with a single command.

## Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Backend & Database**: Firebase Authentication, Cloud Firestore
- **Hosting**: Firebase Hosting
- **Quality Tools**: ESLint, Prettier, Oxlint

## Getting Started
```bash
# Clone the repository (if you haven't already)
git clone https://github.com/7beastgamer/Attendance_tracker.git
cd Attendance_tracker

# Install dependencies
npm install

# Run the development server
npm run dev
```
Open `http://localhost:5173` in your browser to view the app.

## Deployment
```bash
# Log in to Firebase (skip if already authenticated)
firebase login --no-localhost

# Deploy the app to Firebase Hosting
firebase deploy
```
Make sure you have the proper Firebase project selected (`firebase use <project-id>`).

## Project Structure
- `src/` – React components, pages, and hooks.
- `public/` – Static assets (icons, images, etc.).
- `firebase.json` – Configuration for Firebase services.
- `firestore.rules` – Security rules governing Firestore access.
- `vite.config.ts` – Vite build configuration.
- `tailwind.config.js` – Tailwind CSS customizations.
